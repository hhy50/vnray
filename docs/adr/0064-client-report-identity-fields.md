# ADR 0064：客户端独立上报分组与实例名

- 状态：已采纳
- 日期：2026-11-11
- Supersedes：[ADR 0063](0063-client-group-config.md) 中将 group 与 name 拼接进上报 name 字段的约定；保留配置缺省规则。

## 决策

`ConfigReport` 的 `client` 对象使用独立的 `group` 和 `name` 字段，例如 `{"group":"office","name":"desktop-01"}`。客户端不再把分组拼接进上报 name。首报及周期上报使用相同的分组、实例名；服务端拒绝任一字段为空、包含 `:` 或 `*`，也拒绝会话内修改任一字段。

上报快照及落库的配置 JSON 原样保留两个字段。管理台客户端列表和详情返回 `group`、`name`，列表新增分组列，支持按分组搜索。

服务端的绑定键、会话索引、端口映射和流量统计继续使用 `group:name`，与原数据库记录对应。它只作为服务端内部标识和管理 API 的 `key` 字段，不写回客户端上报的 name。管理台通过 key 查询与保存配置，防止不同分组的同名客户端混淆。密钥范围继续使用 `*`、`group:*` 或 `group:name`。`server:self` 继续保留给本机出口。

历史离线记录从已有绑定键取得分组和实例名，历史快照缺少 group 时保留旧绑定键用于读取；新接入不兼容旧上报格式。客户端向服务端上报不包含 key 字段。

## 兼容性

这是配置上报 JSON 语义的 BREAKING 变更，客户端与服务端必须同步升级。旧客户端只上报拼接 name，会因缺少 group 或 name 中含冒号而被拒绝。二进制帧头、消息类型编号、安全握手和密钥生成算法不变。绑定键未变，无需自动改写数据库或重新生成现有密钥。

## 验证

覆盖上报载荷的两个独立字段、缺失与非法身份拒绝、跨分组同名会话、会话内改组或改名拒绝、快照持久化、配置推送、分组授权，以及管理台在线和离线列表、详情、候选项和流量统计。
