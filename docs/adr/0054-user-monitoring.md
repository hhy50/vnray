# 0054 用户与主机监控

监控复用现有用户流量计数器及 Admin 采样生命周期，不引入新依赖或协议消息。
已认证入站 TCP 连接按物理连接计数；stream 是 VNRay 入站流、VMess/VLESS mux
子流或普通代理连接。请求是一次代理目标请求（含被拒绝或建连失败的请求），
不解析隧道中的 HTTP 请求，心跳和 mux 主连接不计请求。

用户流量按成功写出的有效载荷计，上行为用户到出口，下行为出口到用户。
累计请求及监控累计字节从本次进程启动开始，计数不随监控开关清零；原有账务流量不变。
速率使用实际采样间隔，首样及重新开启后的首样速率不可用。

每次采样以一行 JSON 保存主机及用户快照，用户用数据库 ID 关联，不持久化用户凭据。
使用现有 Store，历史跨重启保留，按时间过期；关闭采集仍清理过期记录。
默认 2s/1h，允许 1s–1h 采样、最长 7d 保留，最多 10000 个采样周期。
历史查询先从时间索引选取至多 120 个等间隔样本，再读取载荷，避免全量反序列化。
删除用户后历史不再展示；删除后重建用户的新 ID 不继承旧历史。

Admin 的 /monitoring 合并用户与主机两个 tab；旧 /metrics 重定向到主机 tab。
采样配置在服务端配置页持久化，后台至多 1 秒识别配置变化。
